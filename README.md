# SCOPE Lesson Hub

Lesson hub for middle school speech-language sessions (one laptop, one or two students). 40 SCOPE lessons across 6 units: clues and context, multiple meanings, reading between the lines, relating experiences, solving problems, and speaking up.

**Open the app:** https://kromlor.github.io/Scope-Lesson-Hub/

- Records are saved only in the browser on the computer that opens the link. They do not sync between computers and are never sent anywhere. Use the app's **Backup** page regularly.
- To run it offline, download this repository (Code → Download ZIP), unzip it, and open `index.html` in Chrome or Edge.
- See `START HERE - How to use.txt` for how to run lessons, edit lessons, and back up. See `Verification report.txt` for test results and known limits.

Folders: `js/` app logic · `css/` styles · `content/` lesson content and voice list · `assets/` pictures and warm-voice recordings · `vendor/` zip library · `sample-media/` sample audio.
