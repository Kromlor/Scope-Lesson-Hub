SCOPE LESSON HUB: VERIFICATION REPORT
=====================================
Built October 8, 2026 from SCOPE-Perspective-Lab-Warm-Voice.html (6.4 MB).

WHAT WAS BUILT
- A lesson hub that runs from a folder (index.html + separate folders for app logic, lesson content,
  pictures, and voice clips). The old version was one 6.4 MB file; the app code is about 210 KB,
  and media loads only when shown or played.
- Storage: IndexedDB in the browser on this laptop (lessons, students, sessions, drafts, uploaded media).
  No accounts, no cloud, no AI, no analytics. Nothing is sent anywhere.

WHAT WAS MOVED OVER FROM THE ORIGINAL
- All 8 completed lessons, each with a core lesson and 2 additional-practice parts: 24 parts, 334 cards.
- Every piece of lesson text was checked against the original: 1,000 of 1,000 text strings are present.
- 50 scene illustrations and 19 face close-ups, cropped from the original picture sheets into separate files.
- 377 warm-voice clips (376 lesson lines plus the voice-test line), as .ogg plus .mp3 copies.
- Clue circles, speech lines, tone cards, "SLP peek" modeling notes, sort activities, SLP tips, video-search
  ideas, and the 8 suggested videos with their pause guidance.
- (See "UPDATE: LESSONS 9–40" at the end.)

CHANGES FROM THE ORIGINAL TO KNOW ABOUT
- Ratings are now Independent / With help / Incorrect / Skipped / Not scored, chosen by the SLP.
  The old app pre-filled a mark from the student's taps; the new one shows the first response and
  number of tries as information only.
- Original "tap who can see it" items are now answer choices listing the characters ("choose all").
- The old practice runs rotated scenes and questions automatically. Now each lesson has two fixed
  practice parts (Additional practice 1 and 2), split from the original practice pool.
- NOT carried over (not in the new brief): each student's grade level, 1x/2x/3x weekly schedule,
  automatic "next lesson" pacing, and the per-grade ND ELA standard text in the CSV. Lessons still
  list their standard codes. Tell me if you want any of these back.

REMAINING LIMITATIONS
- Tested in the Chrome engine (headless Chromium). Not yet tried on the SLP's actual laptop, Edge,
  a Chromebook, or an iPad. Please run one practice session there before using it with students.
- Records live in one browser profile on one laptop. Clearing browser data or using another browser
  starts empty. Back up regularly. Opening the app from a SharePoint web link will not work; copy the
  folder to the laptop (a synced OneDrive folder on the laptop is fine).
- The computer voice differs by computer and reads tone lines flat. Tone items are labeled for SLP modeling.
- No second-student (alternate) questions existed in the original, so "Both practice each skill"
  uses the same question with the answer hidden until you add alternates in the editor.
- 21 migrated items (mostly Lesson 3, "How does ___ feel?" from a face) accept only one feeling.
  Since faces are possible clues, not proof, consider marking more answers acceptable or adding
  "Ask them" as an option in the editor.
- The 8 suggested video links go to outside sites (YouTube, Disney, VOA, creators' pages). They need
  internet and were not checked live; sites can move or change.
- The freezing reported in the old app was not reproduced. The rebuild removes the likely risks
  (whole screen redrawn on resize, all media inside one file), but the cause was not confirmed.
- Sample audio (Maya, Alex) is in sample-media and is not attached to any lesson.

UPDATE: LESSONS 9–40 (October 8, 2026)
- Lessons 9–40 (Units 2–6) are now complete core lessons: 32 lessons, 516 cards, same structure as
  lessons 1–8 (warm-up, five SCOPE steps, talk it through, practice, quick check; unit checks have 8
  quick checks). They are new writing, not from the original file. Please read through them before use.
- Only a "Core lesson" part was written for these. The two "Additional practice" parts that lessons 1–8
  have do not exist yet for 9–40.
- Pictures: about half the lessons reuse an existing SCOPE scene on the explore cards, picked to match
  what the picture shows. No new illustrations were made.
- Read-aloud: the warm-voice recordings only cover the original text, so most of the new text uses the
  labeled computer voice. You can upload your own recordings per card in the editor.
- Answer order was shuffled on the new cards so the right answer is not always first.
  Many new cards have 2 answer choices rather than 3.
- Laptops that already opened the app get the new lessons automatically on next open (a message says
  how many were updated). A lesson the SLP had edited is kept as-is; use "Reset to the original version"
  in the editor to get the new one.
- Tests rerun: 15 of 15 pass, including a preview of all 40 lessons (850 cards) with no errors and the
  automatic update of older laptops.
